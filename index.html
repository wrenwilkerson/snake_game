# Snake Game A classic Snake game written in Python with `pygame`, built around object-oriented design. **Live JS version:** playable right on my [portfolio site](https://wrenwilkerson.github.io/portfolio-website/#projects). ## Features - Real-time gameplay with a fixed-tick game loop - Collision detection (walls and self) - Score tracking - Restart on game over ## Design The game is split into three classes: - **`Snake`** — owns the snake's body, movement, growth, and self-collision checks - **`Food`** — spawns at a random empty cell and respawns when eaten - **`Game`** — owns the game loop, input handling, scoring, and rendering ## Requirements - Python 3.8+ - [pygame](https://www.pygame.org/) ```bash pip install pygame ``` ## Running it ```bash python snake_game.py ``` ## Controls | Key | Action | |---|---| | Arrow keys / WASD | Move | | R | Restart after game over | ## Contact - Email: wilkersonwren144@gmail.com - LinkedIn: [linkedin.com/in/wren-wilkerson-349813230](https://linkedin.com/in/wren-wilkerson-349813230) - GitHub: [@wrenwilkerson](https://github.com/wrenwilkerson)
